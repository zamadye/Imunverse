# Character art staging folder

Generated hero character art lands here, **not** directly in
`assets/sprites/`. See `docs/CHARACTER-ART-BRIEF.md` for the full brief:
exact filenames, prompts, resolution, and style rules for every file this
folder should contain.

Claude reviews and integrates files from this folder into the live
`assets/sprites/` runtime path (resizing/optimizing as needed) once they
land — nothing here is read by the running game directly.
